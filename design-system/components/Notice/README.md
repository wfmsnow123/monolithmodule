# Notice

Boxed message inside a window: a diamond sigil, an uppercase title and one or two sentences of body.

## Variants

| class | ground | when |
| --- | --- | --- |
| `mono-notice--danger` | `blood-wash`, `blood-500` border | Destructive or irreversible actions. |
| `mono-notice--info` | `cobalt-wash`, `cobalt-500` border | Help, module descriptions, tips. |
| `mono-notice--warn` | `void-100`, `ichor` border | Reload required, deprecated options. |

## Rules

- Title: 2–4 words. Body: plain, short, says what happens.
- One notice per section at most. For transient feedback use Foundry's `ui.notifications`.
